Face-Recognition based Hostel Entry System

Contactless secure access using InsightFace. The system integrates a Java Swing frontend (webcam capture) with a Python backend (InsightFace embeddings & comparison).

Technical Summary

Overview:
• Frontend: Java Swing to capture webcam frames and send cropped faces (base64) to backend.
• Backend: Python + InsightFace to compute embeddings and compare against stored embeddings (MySQL).
• Response: 'goodpic' returned for recognized users; captured face image returned for unknown faces; nothing returned if no face detected.

Key highlights:
• Efficient embedding comparison (cosine similarity / thresholding).
• Designed for hostel entry with logging for unknown entries.
• Fast recognition loop and UX-friendly feedback (sound / UI flashes).

Tech stack

Python
InsightFace

Notes

  • Embeddings stored in DB for fast lookup.
  • Only send to server when a face is detected (saves bandwidth).
  • Recognized results display a 'goodpic' and trigger access flow.
